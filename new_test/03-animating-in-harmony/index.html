About this lesson

Create, animate and export a complete first scene

Time to jump right into animating in Toon Boom Harmony. In this lesson you will learn how to start, create and export an animated project in Harmony.

The warm-up animation is completed at 24 frames per second and begins by animating on ones. You will create a scene where two dots chase or play with each other as they cross the camera, then change the timing to animating on twos and export the result.

  2. Review animation and Harmony terminology

Animation concepts

These are the animation terms introduced in the original lesson.

01

Animating on Ones

Drawing on every single frame of an animated sequence. It creates smooth animation, but is extremely time consuming.

02

Animating on Twos

Drawing on every second frame, with the following frame holding the previous drawing. This provides fluid animation while taking less time than animating on ones.

03

Animating on Threes

Drawing on every third frame. The lesson notes that this approach is often used in anime to make complex character animation less time consuming on tighter budgets.

Exporting

Compiles an animated project into a playable format. Harmony can export scenes as video files, GIFs, images and more.

Frames Per Second (FPS)

The lesson recommends 24 frames for one second of animation and notes that Harmony's default frame rate is 24 FPS.

Frame Rate

The number of frames played per second. The source lesson explains that at least 12 images per second are needed for movement to avoid looking jumpy.

Frame Size & Pixels

Frame size is the width and height of the camera frame in pixels. A pixel is the smallest element of a digital image, and pixels are composed from RGB colour information: red, green and blue.

Straight Ahead Animation

One of the Principles of Animation. Drawings are created sequentially across many frames on a timeline to produce the optical illusion of movement.

Harmony vocabulary

Know the workspace

Xstage file
The native computer extension for Toon Boom Harmony.
User Interface
Harmony contains a series of views and toolbars used for different operations. Learning to manage the interface helps you work efficiently and organize your workspace.
Colour View
Where you create colours and palettes, import palettes, draw, paint and create colour styling.
Timeline View
The main view for adjusting drawing timing, adding keyframes and ordering layers. It displays layers, effects, sounds, scene length, drawings, timing and frames.
Tools Toolbar
Contains the main tools needed to work in Harmony. In the default workspace it is located on the left edge of the application window.
Camera View
The centre of operations where you can draw, paint, animate, set up a scene, manipulate objects, open symbols and preview animation.
Tool Properties
Shows the most common options for the currently selected tool and updates whenever you choose a different tool.
Onion Skin
Displays previous and next frames of an animation and is useful when animating cut-out and paperless characters.
Exporting in Harmony
Harmony supports several rendering formats depending on whether the animation will be edited elsewhere, composited into a larger project or delivered directly.

Hands-on activity

Fun with Dots

Create two animated dots at 24 FPS, extend the scene from 30 to 60 frames, add a colour card, export an animated GIF and submit your work.

Before you begin

  • Watch and take notes on the Your First Animation video.
  • Review the shortcut PDF for your operating system.
  • Save and export your completed project as YourName_FunWithDots.
Activity progress 0 of 4 steps complete
Step 1

Create the scene

  • Launch Toon Boom Harmony.
  • In the Welcome Window, create a new scene called Dots.
  • Set the location to your Documents folder.
  • Keep the default camera size HDTV_1080p24: 1920 × 1080 pixels at 24 frames per second.
  • Click Create Scene.
  • Select the Brush Tool.
Interface hint: Tools are on the left. Camera and Drawing views are in the middle. The Timeline runs along the bottom. The Colour view sits to the right of the Camera view, with Tool Properties above it.
Step 2

Animate Dot 1 on ones

  • Rename the existing Timeline layer to Dot 1.
  • Keep the Brush Tool selected, choose black in the Colour view and place your cursor in the Camera view.
  • Hold O and drag left/right to change brush size, then draw a dot at the left side of the camera.
  • Use , and . to move to the previous and next frames.
  • Enable Onion Skin so the previous drawing is visible while you animate.
  • Animate the dot across the Camera view over 30 frames. Give it character and use a dynamic path rather than a straight line.
  • Experiment with spacing and brush size. Try elongating some dots to create a sense of movement.
  • At frame 30, set the Timeline Stop value to 30, scrub the animation, adjust drawings as needed, then enable Loop and press Play.
Step 3

Add Dot 2 and animate on twos

  • Save your work with CMD + S or CTRL + S.
  • Add a new Drawing Layer and name it Dot 2.
  • Choose a new brush colour, but avoid red and green because the lesson uses those colours for Onion Skin.
  • Animate Dot 2 so it chases and/or plays with Dot 1 across the Camera view.
  • Test the scene by scrubbing the Playhead or pressing Play.
  • To slow the animation, extend it from 30 to 60 frames and change the drawings to animate on twos.
  • Shift-select the frames across both dot layers, right-click frame 30 and choose Exposure → Set Exposure to 2.
  • Set the Timeline Stop value to frame 60 and play the animation again.
Colour Card hint: Harmony exports with a transparent background by default, which can look black in many video players. A Colour Card lets you choose a background colour and does not need to be extended across every frame.
Step 4

Add a background, export and submit

  • In the Timeline, select the + icon and add a Colour Card.
  • Use the colour control beside the Colour Card layer to choose a background colour.
  • Review your animated scene one more time.
  • Go to File → Export → Animated GIF and choose your Documents folder as the destination.
  • Test the exported animation in a web browser.
  • Submit your exported animation using your school's submission method.
Congrats — you animated your first scene in this course.
