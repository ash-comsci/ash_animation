Lesson 12 - Nodes, Nodes and more Nodes

About This Lesson

In this lesson you will learn about different Filter Nodes in Harmony. The Node view is a visual representation of how every element in your scene (drawing layers, pegs, effects) is combined to form the final image.

It allows you to rig elements together and add a wide range of effects. Mastering the Node view is essential for rigging cut-out models and managing composition.

Harmony Topics: Filter Nodes
  • The Auto-Patch Node: Automatically patches an articulation without line adjustment. Overlap two pieces with complete lines, and this node creates a perfect articulation.
  • The Blending Node: Composites elements using advanced algorithms rather than simple opacity. Useful for effects that need specific blend modes to look correct in the final render.
  • The Box-Blur Node: A quick way to create a blurring effect. Similar to Gaussian blur but renders faster. Useful when speed is important or for isolating areas with a matte.
  • The Composite Node: Takes several input images (drawings, effects) and outputs a single flattened image. Similar to pre-compositions in editing software.
  • The Cutter Node: Hides parts of a drawing based on a matte. You can invert it to make only the intersecting parts visible.
  • The Glow Node: Creates a bright soft-edged light or diffuse region around an image. Useful for shining rims (sun, stars). Connect it twice to the Composite to keep the original image on top.
  • The Shadow Node: Turns a drawing into a grey, semi-transparent, blurry silhouette. Connect your layer a second time to the Composite node to see the original object above its shadow.
  • Render & Render Mode: Most effects (like blurs and glows) must be rendered to be seen properly. Use the "Render Mode" in the Camera view to preview them. If the scene is heavy, turn off "Auto-Render" and update manually.

  • Shadow: Apply the Shadow node to create a drop shadow for CNote. Export image as CNote_Shadow.
  • Cutter: Use the Cutter node to mask part of the character (e.g., hiding part of the body behind an object). Export image as CNote_Cutter.
