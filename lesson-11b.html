Lesson 11 - Drawing Tools Part II: Tracing

About This Lesson

[cite_start]In this lesson, you will continue to build on your knowledge of Harmony's Drawing Tools[cite: 1]. [cite_start]You will learn how to trace a character in Harmony by hand[cite: 3].


[cite_start]schedule Duration: 4 Hours [cite: 4]
Harmony Topics
  • [cite_start]Light Table: Turns on the light table so you can see the previous and subsequent active layers in washed-out colours[cite: 4]. [cite_start]It is useful for designing, animating, or cleaning up your animation[cite: 5].
  • [cite_start]Onion Skin: A powerful feature that allows you to display drawings surrounding your current drawing in washed, semi-transparent outlines[cite: 7]. [cite_start]This streamlines the traditional technique of placing two drawings on a light table to draw the in-between[cite: 6].
settingsSetup: Preparing the Scene

Before beginning the specific tool tasks, set up your project:

    [cite_start]
  • Launch Toon Boom Harmony and create a new scene called Character Sketch[cite: 9].
    • [cite_start]
  • Set location to your Document Folder and keep Camera Size at HDTV_1080p24[cite: 9, 10].
    • [cite_start]
  • Go to File > Import > Images and select CNote_sketch.jpg[cite: 11].
    • [cite_start]
  • Import Settings: Create Layer based on Filename, Keep as Original Bitmap, Alignment: Fit, Alpha: Premultiplied with White[cite: 12, 13].
    • [cite_start]
  • Select the CNote layer, press T (Thumbnail), and set opacity to 50%[cite: 14, 15].
    • [cite_start]
  • Lock the CNote layer so you don't draw on it accidently[cite: 15].
brushPart 1: The Brush Tool

Goal: Trace the inner details of the character.

    [cite_start]
  • Rename your drawing layer to Brush and select the Brush Tool[cite: 16].
    • [cite_start]
  • Tip: Use shortcuts 1, 2, and Spacebar to navigate[cite: 16]. [cite_start]Hold O to resize the brush[cite: 17].
    • [cite_start]
  • Trace the inside of CNote's ears and furry whiskers[cite: 18].
    • [cite_start]
  • Smoothing: Select your stroke, open the Centerline Editor, and modify smoothness in Tool Properties to correct shakiness[cite: 19, 20].
  • Complete tracing CNote using the Brush tool.
    • [cite_start]
  • When finished: Turn off visibility of the Brush layer and Lock it[cite: 21, 22].
  • Export: File > Export > Layout Image. [cite_start]Save as Brush Tool Drawing[cite: 22, 23].
editPart 2: The Pencil Tool

Goal: Trace the outer details using vector pencil lines.

    [cite_start]
  • Create a new Drawing Layer named Pencil and select the Pencil Tool[cite: 24].
    • [cite_start]
  • Trace the outside and inside of CNote's ear[cite: 26].
    • [cite_start]
  • Use the Select Tool to click your stroke, then go to Tool Properties to modify Maximum Size (thickness)[cite: 27, 28].
    • [cite_start]
  • Experiment by selecting a different Pencil preset or texture[cite: 28, 29].
    • [cite_start]
  • Use the Pen Tool Editor to modify the ends of your art lines[cite: 29].
  • Complete tracing CNote. [cite_start]Turn off visibility and Lock the layer[cite: 30, 31].
  • Export: File > Export > Layout Image. [cite_start]Save as Pencil Tool Drawing[cite: 31, 32].
change_historyPart 3: The Shape Tool

Goal: Construct the character using geometric primitives and the Contour Editor.

  • Create a Drawing Layer named Rectangle. [cite_start]Select the Rectangle Tool[cite: 33].
  • Eyebrows: Place a rectangle near the eyebrow. Use the Contour Editor to move points into position. [cite_start]Hold Shift to round the edges[cite: 35, 36].
  • Eyes: Draw a square (hold Shift). [cite_start]Rotate it into a diamond using the Select tool[cite: 38, 39].
      [cite_start]
    • Use Contour Editor to align points to the eye edges[cite: 40].
      • [cite_start]
    • Hold Shift and pull lines to round the diamond into an ellipse[cite: 41].
      • [cite_start]
    • Select points to enable Bezier handles for curving[cite: 42].
      • [cite_start]
    • Duplicate the eye by holding Option/Alt and dragging[cite: 44]. [cite_start]Resize and overlap slightly[cite: 45, 46].
      • [cite_start]
    • Use the Cutter Tool to remove the overlapping line between the eyes[cite: 48, 49].
  • Ears: Draw a rectangle. [cite_start]Use Contour Editor to make a triangle shape[cite: 50, 51]. [cite_start]Hold CMD/CTRL to add points for the furry parts[cite: 53].
  • Face: Use the Line Tool for the face outline and whiskers. [cite_start]Enable "Snap to Contour" in Tool Properties to connect lines[cite: 55, 56].
  • Finish: Add grain to the line art in Tool Properties. [cite_start]Save your work[cite: 57, 58].
  • Export: File > Export > Layout Image. [cite_start]Save as Shape Tool Drawing[cite: 59].
