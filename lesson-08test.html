08 - What is a Peg

Lesson 08 - What is a Peg

[video]

About this Lesson:

In this lesson you’ll learn what a Peg is in Toon Boom Harmony and how it is used to animate artwork. You’ll create a simple walk cycle with the character CNote, using a peg to drive motion and timing.

Lesson Duration: 3 hours

Topics

  • Peg: A layer/node used to animate movement in Harmony. It contains no drawings, but can be attached to drawings, objects, and cameras.
  • Transform Tool: Reposition, scale, rotate, and skew layers in the Camera view. Tip: When positioning a drawing layer, deselect Peg Selection Mode in Tool Properties; otherwise the selection is limited to pegs.
  • Element Node: The core of a scene’s structure—stores drawings, exposes them on the Xsheet/Timeline, and links to a layer for positioning. Elements connect to effects, pegs, and composites to control processing and rendering.
  • Node View: Connect effects and compositing nodes to form a network (node system). Useful for rigging, advanced effects, and visualizing complex scenes. Node order and organization determine compositing flow.
  • Pivot Point: All transformations on a drawing layer (rotate, scale, skew, flip) occur relative to its pivot.
  • Advanced Animation Toolbar / Translate Tool: Pan elements on X/Y/Z and adjust a peg layer’s pivot.

Harmony Topics

Shortcuts introduced in this Lesson:

  • Add Peg: CMD+P (macOS) / CTRL+P (Windows)
  • Add Keyframe: F6 or +KF on the Timeline
  • Create Motion Tween: CMD+K (macOS) / CTRL+K (Windows)
  • Nudge Up: Shift + ↑
  • Paste Special: CMD+B (macOS) / CTRL+B (Windows)

Task

  • Download the support files (Using Pegs) from Lesson Files.
  • Download and review the assessment rubric in Lesson Files.
  • Watch the What’s a Peg? video (above) and take notes.
  • In Harmony, create your own animated version of CNote walking. Save and export as: YourName_CNote_Walk in your Documents folder. Continue taking notes in your sketchbook—terminology and techniques will help with the certification exam.

Part 1 – Setting up CNote in Node View

  • Unzip the Lesson File into your Documents folder.
  • Launch Toon Boom Harmony and open Using_Pegs.xstage.
  • Watch the What’s a Peg? tutorial and take notes.
  • Open Node View (use the + icon in any View area).
  • Locate the CNote_front layer in both Node View and Timeline. Rename it in the Timeline to CNote_F and observe the name updates in the Node layer as well.
  • Enable Animation Mode and select the Transform Tool—CNote turns purple indicating you’re manipulating the drawing layer.
  • Select the CNote_F node layer and press CMD+P / CTRL+P (or click Add Peg in the Timeline) to add a Peg.
  • Select the new Peg in Node View—CNote turns yellow with a bounding box indicating you’re now working on the peg.
  • From the Advanced Animation Toolbar, select Translate. You’ll see the axis marker (green up, red right). Reposition CNote’s pivot (blue rotation point) to the belly button.

Part 2 – Creating a Legless (Hidden Legs) Walk Cycle

  • Make CNote walk toward camera (closer to the Camera).
  • Note the hierarchy in the Timeline: the Peg contains the CNote_F art layer—so the peg controls the artwork.
  • Collapse the Peg layer to hide CNote_F.
  • On Frame 1 of the Peg layer, Add Keyframe (+KF).
  • On Frame 15, Add Keyframe (F6).
  • Select Frame 9, click CNote once to activate Camera View.
  • Hold Shift and tap ↑ once to move CNote up ~10 px. (A keyframe is added on Frame 9.)
  • Select the keyframes on Frames 1 and 15. Press CMD+K / CTRL+K to set Motion Tween—Harmony will create the in‑betweens.
  • Play your scene—CNote should move up and down.
  • Select Frames 1–15, Copy, then select Frame 16 and Paste Special (CMD+B / CTRL+B).
  • In Paste Special, change Cycles Normal from 5 to 3.
